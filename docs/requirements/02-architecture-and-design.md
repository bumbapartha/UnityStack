# Architecture and design phase

[← Requirements](README.md)

Features UnityStack gives its users for the architecture and design phase of *their* projects: diagrams, ADRs, wireframes, UX design, API and technical documentation, and the software catalogue. UnityStack's own architecture is described in [Architecture](../architecture.md); its platform requirements are in [Core platform](10-core-platform.md).

**Tools:** [Design, documentation and developer tools](../tools-and-adapters.md#design-documentation-and-developer-tools)

## Requirements

| ID | Priority | Requirement |
|---|---|---|
| FR-038 | P1 | Generate Mermaid diagrams and ADRs through human-reviewed PRs. |
| FR-039 | P2 | Publish Markdown documentation through MkDocs and OpenAPI specifications through Swagger UI. *(Was P1.)* |
| FR-037 | P0 | Generate and review Excalidraw wireframes and Penpot designs with Git-backed artifacts, after the requirements are approved and before planning. *(Was P2.)* |
| FR-040 | P2 | Register software components in Backstage using Git-versioned catalogue descriptors. *(Was P1.)* |
