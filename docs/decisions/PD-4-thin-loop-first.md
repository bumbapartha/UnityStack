# PD-4 — Thin loop first

[← Decisions](README.md)

**Status:** Accepted · **Date:** 27 November 2026

## Context

Either build the whole loop basic and end to end first, or make one stage solid first. One stage first risks rework when later stages do not fit.

## Decision

Build every stage of the loop in a basic form from end to end, then deepen each stage.

## Consequences

Integration problems (Change ID, adapter design) surface early; every stage is basic for a while. The MVP is the thin loop (roadmap Phases 0–4).
